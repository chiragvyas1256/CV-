# Fine Print Money — Faceless YouTube Channel System

Working name: **Fine Print Money** (rename freely). Faceless US personal-finance explainers.

## Output target
- 2 Shorts per day
- 1 long video (8–10 min) every 3 days
- Every Short is cut from a long video or a standalone hook

## Folders
| Folder | Purpose |
|---|---|
| `LAUNCH_CHECKLIST.md` | One-time channel, AdSense, tools and policy setup |
| `ideas/` | Video idea backlog with keyword angle |
| `calendar/` | 30-day posting schedule |
| `templates/` | Reusable prompts and script formats (paste into Claude) |
| `scripts/` | Finished scripts, one file per long video + its Shorts |

## Weekly workflow (about 6 hrs/week once routine)
1. **Mon** – Ask Claude for the week's 2–3 long scripts using `templates/prompts.md` (Prompt 2). Fact-check every number against the cited source.
2. **Tue** – Voiceover (ElevenLabs or similar), then edit long videos in CapCut/Descript.
3. **Wed** – Ask Claude to cut each long script into 4 Shorts (Prompt 4). Edit Shorts in batch.
4. **Thu** – Thumbnails + titles (Prompt 5). Schedule uploads in YouTube Studio.
5. **Fri** – Check analytics: CTR, average view duration, Shorts-to-subscriber rate. Feed results into Prompt 7.

## Non-negotiables
- Original angle, real numbers and cited sources in every video (YouTube "inauthentic content" policy).
- Disclaimer in description and spoken in video: educational, not financial advice.
- Declare AI voice/synthetic visuals in YouTube Studio where it asks.
