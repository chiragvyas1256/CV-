# Instagram AI Content Engine

A daily system for turning AI/tech news into Reels.

- **[SOURCES.md](SOURCES.md)** — the websites to read every day, ranked, plus the 4-gate filter
- **[SCRIPT-FORMULA.md](SCRIPT-FORMULA.md)** — the 5-beat script structure, hook formulas, caption template, posting rules
- **[EXAMPLE-SCRIPT.md](EXAMPLE-SCRIPT.md)** — what a finished daily script looks like

## Daily loop (35 min total)
1. **15 min** — read Tier 1, pull 3 candidate stories, run the 4-gate filter
2. **10 min** — write the script using the 5-beat structure
3. **10 min** — shoot, subtitle, post 8-10 PM IST, stay for comments
