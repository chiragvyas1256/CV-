# Launch Checklist

## Channel
- [ ] Brand Google account (not personal)
- [ ] Final channel name, handle, and `.com` check
- [ ] Banner, avatar, 1-line description ("Plain-English money explainers for Americans. New videos every 3 days.")
- [ ] Country = United States; default language English; upload defaults: category *Education*, "Not made for kids"
- [ ] Standard disclaimer saved as an upload default description footer
- [ ] Channel trailer: 45 s, "what you'll get here"

## Tools (all low-cost)
- [ ] Voice: ElevenLabs (pick one American voice and keep it for brand consistency)
- [ ] Editor: CapCut (fast) or Descript (script-based editing)
- [ ] Visuals: Pexels/Pixabay/Storyblocks stock, screen recordings, simple animated charts (Canva / Flourish), optional AI visuals
- [ ] Thumbnails: Canva (one reusable template)
- [ ] Music: YouTube Audio Library or Epidemic Sound
- [ ] Research: IRS.gov, CFPB, FDIC, SEC, Fed, BLS (primary sources only)

## Monetization (AdSense)
- [ ] Create AdSense account tied to the channel
- [ ] Enable 2-step verification on the Google account
- [ ] Track: 1,000 subs + 4,000 public watch hours (12 mo) **or** 500 subs for early fan-funding tier; Shorts path: 10M views/90 days
- [ ] US tax info (W-9 for US residents / W-8BEN otherwise) completed in AdSense when prompted
- [ ] Extra income to stack later: affiliate links (high-yield savings, brokerages, tax software), newsletter, sponsorships

## Policy guardrails
- [ ] Every video has a cited source list in the description
- [ ] No guaranteed-returns or "get rich quick" claims (limited ads / strikes risk)
- [ ] No unlicensed advice phrasing: "here's how it works" not "you should buy X"
- [ ] Disclose AI voice / altered visuals in Studio when prompted
- [ ] Never reuse other creators' footage or scripts
- [ ] Vary format, hooks, and visuals across videos so the channel doesn't read as templated mass production
